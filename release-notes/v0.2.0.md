## What's new

**A welcome guide for first launch.** Five short steps get yewclic working without opening Settings:

- **Pick a brain:** choose between *Free and private* (Ollama or LM Studio on your Mac), *My Claude plan* (Claude Code, no key needed) or *An API key* (Claude, OpenAI, Gemini, Mistral, DeepSeek, Qwen, OpenRouter, Groq). It checks that it works before you move on.
- **Permissions, explained:** each one says exactly why it's needed. If macOS needs yewclic to restart to apply one, the guide does that and reopens where you left off.
- **Voice:** turn spoken answers on or off, choose a voice and play a sample.
- **Try it:** hold ⌃⌥, ask a question, and watch it listen, think and answer.

Reopen it any time from **Yewclic → Welcome Guide…**.

## Also in this release

- Unit tests for the guide, the pointing tags and multi-monitor mapping, run on every change.
- Every build on GitHub now saves screenshots of the guide (light and dark).

## Install

Download `Yewclic-v0.2.0.zip`, unzip, and drag **Yewclic.app** to Applications. The app isn't notarised yet, so the first time, right-click it and choose **Open**.

Requires macOS 14.2 or later.
